# Code of Conduct

We follow the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be respectful, welcoming and constructive; no harassment or discrimination.

Report unacceptable behaviour privately via a GitHub security advisory or by
contacting the maintainers through the GitHub repository. Maintainers
may remove contributions or restrict participation that violates these norms.
