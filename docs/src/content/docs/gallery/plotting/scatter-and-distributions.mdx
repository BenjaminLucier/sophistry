Marks that show individual observations or summarise how they spread. Start with `ScatterWithErrorBars`, then `StripAndSwarm` and `BoxAndViolin`. The point-heavy marks here (`Scatter`, `Strip`, `Beeswarm`, `Rug`) always paint as one batched layer, with hover still resolved per point; see [Batched rendering](/project/performance/#batched-rendering).
