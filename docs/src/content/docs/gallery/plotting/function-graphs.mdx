Hand-built plots: an `Axes`, `NumberPlane` or `PolarPlane` maps data coordinates to scene units, and graphs, areas and slopes are drawn in it. Start with `SinAndCosFunctionPlot`; `AreaUnderCurve` and `SecantToTangent` are the calculus visuals.
