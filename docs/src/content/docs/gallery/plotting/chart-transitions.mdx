Charts redraw from their data, so animating the data animates the chart: a new `data` value (a track, or a plain prop) reconciles items by key, and with a transition, tweens what changed. Start with `BarChartMorph`, then the `Keyed*` examples, which join two datasets by key so items enter, leave and move. `SortedBars` and `BarChartRace` animate order; `StreamingSeries` slides the domain.
