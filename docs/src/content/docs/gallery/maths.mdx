LaTeX in sophistry is geometry, not an image: `MathTex` turns a formula into outlines you can `draw`, `write` or recolor, and `MathTransform` morphs one formula into another by matching shared symbols. The components come from `@sophistry/solidjs/text` and the definitions from `@sophistry/text`, a separate package, so KaTeX and opentype.js are bundled only when you use it.

Start with `EulerIdentity` and `QuadraticFormula` for typesetting, then `FormulaMorph`. The remaining examples combine formulas with graphs, planes and linear maps.
