Interaction in sophistry writes to the same tracks that animations drive. A `draggable` (or `useMovablePoint`) updates a track, constraints (`onCircle`, `snapToGrid`, `toBounds`) shape where it may go, and every prop bound to that track, directly or through `derive`, follows it. Nodes also take event props (`onClick`, `onDrag`, ...). Every draggable is also a keyboard-focusable tab stop, so these scenes work without a pointer.

Start with [Dragging and input](/gallery/interaction/dragging-and-input/) (`DragConstraints`, then `KeyboardAccessible`). [Cameras, zoom and drill-down](/gallery/interaction/cameras-and-zoom/) moves the view instead of the scene.
