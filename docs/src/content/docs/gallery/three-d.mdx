`@sophistry/3d` projects 3D into 2D: a `<Camera3D>` (from `@sophistry/solidjs/3d`) inside a normal `<Stage>` turns points into screen positions, and 3D primitives paint onto the same canvas, so tracks, animations and themes work unchanged. The camera eye is a plain track, which is why `rotateBy` can spin it and `useOrbitControls3D` can drag it. 3D charts come from `@sophistry/charts/3d`.

Start with `OrbitScene`, then `HelixCurve` and `SurfacePlot3D`. `CameraMotion` shows animating the camera.
