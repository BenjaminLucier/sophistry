# sophistry (Python): reserved placeholder

This package is a **placeholder**. It reserves the `sophistry` name for
possible future Python bindings to [sophistry](https://sophistry.dev), a
controllable Manim-for-the-web animation and visualization library for SolidJS.

There is **nothing usable here yet**: the only code is a stub `hello()` function.
No API is planned or promised, and nothing in it is covered by the stability
policy of the JavaScript library.

The real project is the JavaScript/TypeScript library, `@sophistry/core`:

- Documentation and gallery: <https://sophistry.dev>
- Source and issues: <https://github.com/BenjaminLucier/sophistry>
- npm: <https://www.npmjs.com/package/@sophistry/core>

If you would like Python bindings, open a discussion on the GitHub repository
and describe your use case.
